## About

I design and deliver AI powered products end to end, from database and API design through to deployment, monitoring and production support.

My work sits in three areas. **Generative AI and agentic systems**, building agents that reason over context, call tools, take real actions and hand over to a human when they are not confident. **Automation**, connecting business systems so repetitive work runs on its own with retries, logging and alerting rather than silent failure. And **full stack engineering**, the APIs, data models, frontends and infrastructure that hold all of it together.

- Building **AI agents** with Claude, OpenAI and Gemini using tool and function calling, conversation memory and confidence based human handover
- Building **RAG pipelines** with ingestion, chunking, embeddings, hybrid retrieval, reranking and cited sources so answers come from real company data
- Building **custom MCP servers** that expose internal systems to AI assistants through defined, permissioned tools
- Building **automation systems** in n8n, Make, Zapier and GoHighLevel, and in code when a workflow outgrows the visual builder
- Owning the **DevOps** side, Docker, CI/CD, cloud deployment, monitoring and live production support
- **700+ DSA problems** solved on LeetCode and an **ICPC 2025 Regional** participant

**Currently** Full Stack AI Engineer at **Qeyafa Vision AI**, building AI powered products for production users.

## How I Build

Every system I ship is built to survive a bad day, not just a demo. That means retries with backoff, rate limit handling, idempotency so a duplicate event never creates a duplicate record, structured logging of every run, and alerting so failures surface immediately instead of being discovered by a customer.

I also work daily inside AI assisted development tools, using Claude Code and Cursor for architecture planning, implementation, testing, code review and refactoring, while keeping human review on everything that ships.
